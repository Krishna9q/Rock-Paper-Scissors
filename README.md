# ✊✋✌️ Rock Paper Scissors Game

Play the timeless game of **Rock Paper Scissors** against a computer opponent! This web-based version was created using **HTML, CSS, and JavaScript** for an interactive and fun experience.

![Rock Paper Scissors Screenshot](https://github.com/user-attachments/assets/dadafb52-afd6-412c-8347-703c5e9a4bf9) <!-- Add a screenshot of your game here -->

## 🎯 Features

- **Interactive Gameplay**: Choose Rock, Paper, or Scissors to play against the computer.
- **Dynamic Results Display**: See if you win, lose, or tie instantly.
- **Score Tracking**: Your score and the computer’s score are displayed in real time.
- **Responsive Design**: Enjoy the game on both desktop and mobile devices.

## 🤖 How to Play

1. Choose one of the three options: **Rock**, **Paper**, or **Scissors**.
2. The computer will randomly select its choice.
3. Results are instantly displayed with a **Win**, **Lose**, or **Draw** message.
4. The **scoreboard** keeps track of your wins and losses.

## 🛠️ Technologies Used

- **HTML**: For the game structure and elements.
- **CSS**: Styling for the layout, buttons, and scoreboard.
- **JavaScript**: Handles game logic, random computer choices, and score management.
